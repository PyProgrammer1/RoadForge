# RoadForge

A customizable native iOS navigation app powered by OpenStreetMap.

## Current Status

RoadForge v0.1 is a starter project.

- SwiftUI application shell
- Basic map placeholder
- CoreLocation permission handling
- GitHub Actions iOS build
- Unsigned IPA packaging for Sideloadly

## Planned Features

- MapLibre map rendering
- OpenStreetMap data
- Custom road, building, water and terrain textures
- GPS location tracking
- Search
- Route calculation
- Turn-by-turn navigation
- Custom voice profiles
- AI-generated navigation voices
- Apple CarPlay
- Offline map support
